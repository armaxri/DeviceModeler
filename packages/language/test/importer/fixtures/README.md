# itemis CREATE test fixtures

The `.sct` files in this folder are itemis CREATE (formerly YAKINDU Statechart Tools) models used to
test the importer (`src/importer/sct-importer.ts`). They were copied unchanged from the public
repository [itemisCREATE/statecharts](https://github.com/itemisCREATE/statecharts)
(commit `4d7dd078d15df02a4c03e8219509b35c9cfcb4e3`); only an XML comment with the source URL and the license was added after the XML
declaration.

the source repository. They are used as test data only.
